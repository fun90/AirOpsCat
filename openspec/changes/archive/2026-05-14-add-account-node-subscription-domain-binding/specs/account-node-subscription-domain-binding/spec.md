## ADDED Requirements

### Requirement: 管理员可以维护账户节点订阅域名绑定
系统 SHALL 允许管理员为指定账户在指定节点上配置一个用于订阅输出的 DNS 记录完整域名绑定，并允许查看、更新、启用、禁用和删除该绑定。

#### Scenario: 创建账户节点订阅域名绑定
- **WHEN** 管理员为某账户选择一个节点和一个 DNS 记录并保存
- **THEN** 系统 MUST 持久化该账户在该节点上的订阅域名绑定，并引用该 DNS 记录

#### Scenario: 选择账户可用节点
- **WHEN** 管理员为某账户维护节点订阅域名绑定
- **THEN** 系统 MUST 只向管理员提供该账户通过标签授权得到的节点作为可选节点
- **AND** 系统 MUST 默认加载前 20 条可选节点

#### Scenario: 保存非账户可用节点绑定
- **WHEN** 管理员或客户端提交的节点不属于该账户通过标签授权得到的节点集合
- **THEN** 系统 MUST 拒绝保存该绑定

#### Scenario: 查看账户的节点订阅域名绑定
- **WHEN** 管理员查看某账户的节点订阅域名绑定列表
- **THEN** 系统 MUST 返回该账户已配置的节点、DNS 记录完整域名、启用状态和更新时间

#### Scenario: 查看节点的账户订阅域名绑定
- **WHEN** 管理员查看某节点的账户订阅域名绑定列表
- **THEN** 系统 MUST 返回该节点已配置的账户、DNS 记录完整域名、启用状态和更新时间

#### Scenario: 禁用账户节点订阅域名绑定
- **WHEN** 管理员禁用某账户在某节点上的订阅域名绑定
- **THEN** 系统 MUST 保留绑定记录并在后续订阅生成时不使用该绑定

#### Scenario: 删除账户节点订阅域名绑定
- **WHEN** 管理员删除某账户在某节点上的订阅域名绑定
- **THEN** 系统 MUST 移除该绑定，并在后续订阅生成时回退到节点默认连接地址

### Requirement: 同一账户同一节点只能绑定一个订阅域名
系统 SHALL 保证同一账户在同一节点上最多存在一个订阅域名绑定。

#### Scenario: 为同一账户同一节点重复创建绑定
- **WHEN** 管理员为已存在绑定的账户和节点再次选择 DNS 记录并保存
- **THEN** 系统 MUST 更新既有绑定的 DNS 记录，而不是创建第二条绑定

#### Scenario: 并发创建同一账户同一节点绑定
- **WHEN** 多个请求同时为同一账户和同一节点创建订阅域名绑定
- **THEN** 系统 MUST 通过唯一约束或等价机制保证最终最多只有一条有效绑定记录

#### Scenario: 同一账户绑定多个节点
- **WHEN** 管理员为同一账户的不同节点分别配置订阅域名绑定
- **THEN** 系统 MUST 允许这些绑定同时存在

#### Scenario: 同一节点绑定多个账户
- **WHEN** 管理员为同一节点上的不同账户分别配置订阅域名绑定
- **THEN** 系统 MUST 允许这些绑定同时存在

### Requirement: 订阅生成优先使用账户节点订阅域名绑定
系统 SHALL 在订阅生成时先按现有标签授权规则确定账户可用节点，再对存在启用绑定的账户节点组合使用绑定 DNS 记录的 `full_name` 覆盖订阅中的节点连接地址。

#### Scenario: 账户订阅节点存在启用绑定
- **WHEN** 账户生成订阅且某个可用节点存在该账户的启用订阅域名绑定
- **THEN** 系统 MUST 在订阅输出中使用绑定 DNS 记录的 `full_name` 作为该节点连接地址

#### Scenario: 账户订阅节点不存在绑定
- **WHEN** 账户生成订阅且某个可用节点不存在该账户的订阅域名绑定
- **THEN** 系统 MUST 保持现有节点地址解析逻辑

#### Scenario: 账户订阅节点绑定已禁用
- **WHEN** 账户生成订阅且某个可用节点的账户节点订阅域名绑定处于禁用状态
- **THEN** 系统 MUST 忽略该绑定并保持现有节点地址解析逻辑

#### Scenario: 绑定域名不可用
- **WHEN** 账户生成订阅且绑定关联的 DNS 记录不存在或 `full_name` 为空
- **THEN** 系统 MUST 忽略该绑定并保持现有节点地址解析逻辑

#### Scenario: 账户没有通过标签获得节点授权
- **WHEN** 账户未通过现有标签授权获得某个节点，但该账户和该节点存在订阅域名绑定
- **THEN** 系统 MUST 不因为该绑定把该节点加入账户订阅

### Requirement: 账户节点订阅域名绑定不影响节点部署
系统 SHALL 将账户节点订阅域名绑定限定为订阅输出覆盖能力，不改变节点部署、部署快照和节点用户列表生成。

#### Scenario: 修改绑定不标记节点待部署
- **WHEN** 管理员创建、更新、禁用或删除账户节点订阅域名绑定
- **THEN** 系统 MUST 不因为该绑定变更将相关节点标记为待部署

#### Scenario: 节点用户列表仍由标签推导
- **WHEN** 系统生成节点部署配置中的用户列表
- **THEN** 系统 MUST 继续根据节点标签和账户标签推导用户集合，而不读取账户节点订阅域名绑定

#### Scenario: 部署快照不包含账户节点订阅域名绑定
- **WHEN** 系统记录节点部署快照或恢复部署版本
- **THEN** 系统 MUST 不把账户节点订阅域名绑定写入节点部署快照
