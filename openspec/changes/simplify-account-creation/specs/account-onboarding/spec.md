## ADDED Requirements

### Requirement: 一站式创建用户与首个账户
系统 SHALL 允许管理员在账户新增流程中填写新用户资料和账户资料，并通过一次提交创建新用户及其首个账户。

#### Scenario: 成功创建新用户及账户
- **WHEN** 管理员提交合法且未被占用的用户资料和合法账户资料
- **THEN** 系统 MUST 创建用户和关联该用户的账户，并返回新用户及新账户的标识和展示信息

#### Scenario: 自动生成账户标识
- **WHEN** 管理员在一站式创建时将账户编号、UUID 或认证码留空
- **THEN** 系统 MUST 沿用现有账户创建规则生成对应值

### Requirement: 一站式创建保持原子性
系统 SHALL 在同一事务中创建新用户、首个账户、账户标签及可选首期交易，任一环节失败时不得保留部分创建结果。

#### Scenario: 账户校验失败
- **WHEN** 新用户资料合法但账户资料校验失败
- **THEN** 系统 MUST 拒绝请求且不得保留本次提交的新用户或账户

#### Scenario: 用户邮箱重复
- **WHEN** 管理员提交的邮箱已被现有用户占用
- **THEN** 系统 MUST 返回明确的邮箱冲突错误且不得创建账户

#### Scenario: 标签关联失败
- **WHEN** 请求中的账户标签不存在或无法关联
- **THEN** 系统 MUST 回滚本次创建的用户、账户和标签关联

#### Scenario: 首期交易创建失败
- **WHEN** 用户、账户和标签资料合法但首期交易无法持久化
- **THEN** 系统 MUST 回滚本次创建的用户、账户、标签关联和交易

### Requirement: 支持为已有用户新增账户
系统 SHALL 在同一账户新增弹窗中允许管理员切换为已有用户模式，并选择一个现有用户创建账户。

#### Scenario: 为已有用户创建账户
- **WHEN** 管理员选择已有用户并提交合法账户资料
- **THEN** 系统 MUST 仅创建关联该用户的新账户，不得创建重复用户

#### Scenario: 用户来源互斥校验
- **WHEN** 请求同时提交已有用户标识和新用户资料，或两者均未提交
- **THEN** 系统 MUST 拒绝请求并提示管理员选择且仅选择一种用户来源

#### Scenario: 已有用户不存在
- **WHEN** 管理员提交的已有用户标识不存在
- **THEN** 系统 MUST 拒绝请求且不得创建账户

### Requirement: 一站式开户表单校验与反馈
系统 SHALL 根据当前用户关联模式校验所需字段，并在创建失败后保留管理员已填写的表单内容以便修正。

#### Scenario: 精简用户资料并填写账号备注名
- **WHEN** 管理员选择创建新用户并填写开户表单
- **THEN** 系统 MUST 不展示用户备注名和用户备注输入项，并 MUST 将账号备注名展示在账号字段之后且要求填写非空值

#### Scenario: 新用户必填信息缺失
- **WHEN** 管理员选择创建新用户但未填写合法邮箱或不少于六个字符的密码
- **THEN** 系统 MUST 阻止提交并在对应字段显示校验信息

#### Scenario: 创建失败后修正重试
- **WHEN** 组合创建请求被后端拒绝
- **THEN** 系统 MUST 保持弹窗和已填写内容，并展示后端返回的可操作错误信息

#### Scenario: 创建成功后刷新列表
- **WHEN** 用户和账户创建成功
- **THEN** 系统 MUST 关闭弹窗、重置新增表单并刷新账户列表及统计数据

### Requirement: 开户时登记首期交易流水
系统 SHALL 在账户新增表单中提供首期金额和付款方式，并在管理员填写正金额时创建一条与续期结构一致、关联新账户的收入交易流水。

#### Scenario: 填写首期金额和付款方式
- **WHEN** 管理员填写正数首期金额、选择合法付款方式并成功创建账户
- **THEN** 系统 MUST 创建 `INCOME` 类型交易，金额和付款方式等于提交值，`businessTable` 为 `account`，`businessId` 为新账户 ID

#### Scenario: 交易描述记录首期有效期
- **WHEN** 系统为新账户创建首期交易流水
- **THEN** 交易描述 MUST 标识该流水为账号首期费用及账户开始时间至到期时间对应的有效期

#### Scenario: 未填写首期金额
- **WHEN** 管理员将首期金额留空并创建账户
- **THEN** 系统 MUST 创建账户但不得生成首期交易流水，行为与续期未填写金额时一致

#### Scenario: 填写金额但未选择付款方式
- **WHEN** 管理员填写首期金额但未选择付款方式
- **THEN** 系统 MUST 拒绝提交并提示选择付款方式，且不得创建用户、账户或交易

#### Scenario: 首期金额不合法
- **WHEN** 管理员提交零、负数或无法解析的首期金额
- **THEN** 系统 MUST 拒绝提交并提示输入有效金额，且不得创建用户、账户或交易

#### Scenario: 返回首期交易结果
- **WHEN** 组合创建成功且生成了首期交易
- **THEN** 系统 MUST 在响应中返回新用户、新账户和首期交易的展示信息
