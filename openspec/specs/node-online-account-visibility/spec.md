## Purpose
Define how AirOpsCat records online account connections by logical node and exposes node/account online connection visibility to administrators.
## Requirements
### Requirement: 在线连接记录必须区分逻辑节点
系统 SHALL 在基于 sing-box 连接信息刷新账户在线记录时，尽可能将连接归属到 AirOpsCat 逻辑节点，并在在线连接记录中保存节点区分信息。

#### Scenario: 连接包含可映射的入站标识
- **WHEN** sing-box 连接 metadata 包含可映射到 AirOpsCat 节点的入站标识
- **THEN** 系统在在线记录中保存对应节点 ID 和节点标识

#### Scenario: 连接缺少可映射的入站标识
- **WHEN** sing-box 连接 metadata 缺少入站标识或无法映射到 AirOpsCat 节点
- **THEN** 系统仍保存服务器维度在线记录，并允许节点字段为空

#### Scenario: 同一账户同一客户端 IP 连接同一服务器的多个节点
- **WHEN** 同一账户的同一客户端 IP 同时连接同一服务器上的多个节点
- **THEN** 系统为不同节点保留独立在线记录

### Requirement: 管理员必须能在节点上查看当前在线账户
系统 SHALL 提供节点维度的当前在线账户查询能力，返回当前有效在线窗口内归属于指定节点的在线账户记录。

#### Scenario: 管理员查看节点在线账户
- **WHEN** 管理员请求某个节点的在线账户详情
- **THEN** 系统返回该节点当前有效在线窗口内的在线账户、客户端 IP、最后在线时间和在线时长

#### Scenario: 节点当前无在线账户
- **WHEN** 管理员请求某个节点的在线账户详情且该节点没有当前有效在线记录
- **THEN** 系统返回空列表

#### Scenario: 请求不存在的节点
- **WHEN** 管理员请求不存在节点的在线账户详情
- **THEN** 系统返回未找到响应

### Requirement: 管理员必须能查看在线连接数和连接详情
系统 SHALL 在管理界面展示账户或节点的当前在线连接数，并提供查看在线连接详情的入口。

#### Scenario: 管理员查看账户在线连接数
- **WHEN** 管理员打开账户列表或账户详情
- **THEN** 系统展示该账户当前有效在线连接数

#### Scenario: 管理员查看节点在线连接数
- **WHEN** 管理员打开节点列表或节点详情
- **THEN** 系统展示该节点当前有效在线连接数

#### Scenario: 管理员查看在线连接详情
- **WHEN** 管理员点击账户或节点的在线连接查看入口
- **THEN** 系统展示当前有效在线连接列表，包含账户、连接 ID、客户端 IP、服务器 IP、节点、最后在线时间和在线时长

### Requirement: 账户在线连接详情必须展示节点区分信息
系统 SHALL 在账户在线连接详情中展示每条在线记录对应的服务器和节点信息。

#### Scenario: 账户在线记录带有节点信息
- **WHEN** 管理员查看账户在线连接详情且记录已映射到节点
- **THEN** 系统展示该记录的节点名称或节点标识

#### Scenario: 账户在线记录只有服务器信息
- **WHEN** 管理员查看账户在线连接详情且记录未映射到节点
- **THEN** 系统仍展示服务器 IP，并以空节点信息或未识别节点状态呈现

### Requirement: 节点列表必须展示当前在线数量入口
系统 SHALL 在节点管理界面提供节点当前在线账户数量及查看入口。

#### Scenario: 节点存在当前在线账户
- **WHEN** 节点列表加载且某个节点存在当前有效在线记录
- **THEN** 系统展示该节点在线账户数量并提供查看详情入口

#### Scenario: 节点没有当前在线账户
- **WHEN** 节点列表加载且某个节点没有当前有效在线记录
- **THEN** 系统展示空状态或零数量，不阻塞节点列表使用

### Requirement: 在线状态刷新必须通过 Clash API 主动采集
系统 SHALL 在刷新账号在线状态时通过 sing-box Clash API 读取当前连接列表，并使用连接中的账号、客户端 IP、连接 ID、节点标识和连接开始时间维护在线记录。

#### Scenario: Clash API 连接列表可用
- **WHEN** 系统刷新某台服务器的账号在线状态且 Clash API 返回当前连接列表
- **THEN** 系统使用连接列表刷新账号在线记录

#### Scenario: Clash API 连接列表不可用
- **WHEN** 系统刷新某台服务器的账号在线状态但 Clash API 不可达、超时或返回异常
- **THEN** 系统记录该服务器刷新失败原因
- **AND** 系统跳过该服务器本轮刷新，不影响其他服务器

#### Scenario: 连接映射到节点
- **WHEN** Clash API 连接 metadata 中包含可映射到 AirOpsCat 节点的节点标识
- **THEN** 系统在在线记录中保存对应节点 ID 和节点标识

#### Scenario: 连接无法映射到节点
- **WHEN** Clash API 连接 metadata 中缺少节点标识或无法映射到 AirOpsCat 节点
- **THEN** 系统仍保存服务器维度在线记录
- **AND** 节点字段允许为空

### Requirement: 管理页在线详情必须复用在线状态记录
系统 SHALL 让当前管理页中的账号在线详情、节点在线详情和服务器在线账号详情复用在线状态刷新写入的在线记录，不为这些页面引入独立的数据源。

#### Scenario: 管理员查看账号在线详情
- **WHEN** 管理员打开账号在线连接详情
- **THEN** 系统从当前有效在线记录返回连接 ID、客户端 IP、服务器 IP、节点信息、最后在线时间和在线时长

#### Scenario: 管理员查看节点在线详情
- **WHEN** 管理员打开节点在线连接详情
- **THEN** 系统从当前有效在线记录返回账号、连接 ID、客户端 IP、服务器 IP、最后在线时间和在线时长

#### Scenario: 管理员查看服务器在线账号详情
- **WHEN** 管理员打开服务器在线账号详情
- **THEN** 系统从当前有效在线记录返回账号、客户端 IP、最后在线时间和在线时长

### Requirement: 管理员必须能查看所有节点每日在线账户趋势总览
系统 SHALL 提供所有节点每日在线账户趋势总览页面，基于节点每日在线账户统计数据展示整体趋势和节点横向对比。

#### Scenario: 管理员打开所有节点趋势总览
- **WHEN** 管理员打开所有节点每日在线账户趋势总览页面
- **THEN** 系统展示所选周期内的全节点在线账户趋势摘要
- **AND** 系统展示整体每日在线账户趋势图
- **AND** 系统展示节点横向对比信息

#### Scenario: 管理员切换总览统计范围
- **WHEN** 管理员在所有节点趋势总览页面选择近 7 天、近 30 天或近 90 天
- **THEN** 系统按所选范围刷新摘要、整体趋势图和节点对比数据

#### Scenario: 所有节点存在统计数据
- **WHEN** 查询范围内存在一个或多个节点的每日在线账户统计数据
- **THEN** 系统展示全节点每日去重在线账户数趋势
- **AND** 系统展示全节点每日峰值在线账户数趋势
- **AND** 系统展示节点峰值排行或使用情况排行

#### Scenario: 查询范围内没有任何节点统计数据
- **WHEN** 管理员打开所有节点趋势总览且查询范围内没有每日统计数据
- **THEN** 系统展示空状态
- **AND** 系统保留统计范围切换和返回节点列表入口

#### Scenario: 管理员从总览页查看单节点趋势
- **WHEN** 管理员在所有节点趋势总览页面点击某个节点
- **THEN** 系统打开该节点的每日在线账户趋势页面

### Requirement: 节点管理界面必须提供所有节点趋势总览入口
系统 SHALL 在节点管理界面提供进入所有节点每日在线账户趋势总览的入口。

#### Scenario: 管理员查看节点列表
- **WHEN** 管理员打开节点列表页面
- **THEN** 系统展示所有节点每日在线账户趋势总览入口

#### Scenario: 管理员点击总览入口
- **WHEN** 管理员点击所有节点趋势总览入口
- **THEN** 系统打开所有节点每日在线账户趋势总览页面

### Requirement: 系统必须沉淀节点每日在线账户统计
系统 SHALL 基于当前有效在线状态记录生成节点每日在线账户统计，并按逻辑节点保存每日数据。

#### Scenario: 定时采样节点在线账户数
- **WHEN** 节点在线账户统计任务执行
- **THEN** 系统按逻辑节点统计当前有效在线窗口内的去重账户数量
- **AND** 系统将统计结果写入当天的节点每日在线账户统计

#### Scenario: 同一账户存在多条连接
- **WHEN** 同一账户在同一节点存在多条当前有效在线记录
- **THEN** 系统在该节点的在线账户数量中只计算一次该账户

#### Scenario: 在线记录没有逻辑节点归属
- **WHEN** 当前有效在线记录缺少逻辑节点 ID
- **THEN** 系统不将该记录计入任一节点的每日在线账户统计

#### Scenario: 同一天多次采样同一节点
- **WHEN** 系统在同一天对同一节点执行多次在线账户统计
- **THEN** 系统更新当天的最近采样在线账户数和最后采样时间
- **AND** 系统保留当天峰值在线账户数
- **AND** 系统累计当天去重在线账户数

### Requirement: 管理员必须能查看节点每日在线账户趋势
系统 SHALL 提供节点每日在线账户趋势页面，展示指定节点在指定天数范围内的每日在线账户统计。

#### Scenario: 管理员从节点进入趋势页面
- **WHEN** 管理员打开某个节点的每日在线账户趋势页面
- **THEN** 系统展示节点名称、节点编号、服务器信息和统计摘要
- **AND** 系统展示每日在线账户数量趋势图

#### Scenario: 管理员切换统计范围
- **WHEN** 管理员在趋势页面选择近 7 天、近 30 天或近 90 天
- **THEN** 系统按所选范围刷新摘要和趋势图数据

#### Scenario: 节点存在统计数据
- **WHEN** 指定节点在查询范围内存在每日统计数据
- **THEN** 系统展示每日去重在线账户数和每日峰值在线账户数
- **AND** 系统展示周期峰值、周期平均值、今日当前值和今日峰值

#### Scenario: 节点没有统计数据
- **WHEN** 指定节点在查询范围内没有每日统计数据
- **THEN** 系统展示空状态
- **AND** 系统不影响页面返回和节点管理流程

#### Scenario: 请求不存在的节点趋势
- **WHEN** 管理员请求不存在节点的每日在线账户趋势
- **THEN** 系统返回未找到响应或页面错误提示

### Requirement: 节点列表必须提供每日在线账户趋势入口
系统 SHALL 在节点管理界面为每个节点提供每日在线账户趋势查看入口。

#### Scenario: 管理员查看节点列表
- **WHEN** 节点列表加载完成
- **THEN** 每个节点的操作区域提供查看每日在线账户趋势的入口

#### Scenario: 管理员点击趋势入口
- **WHEN** 管理员点击某个节点的每日在线账户趋势入口
- **THEN** 系统打开该节点的每日在线账户趋势页面

#### Scenario: 节点当前无在线账户
- **WHEN** 节点当前在线账户或在线连接数量为零
- **THEN** 系统仍提供每日在线账户趋势入口
