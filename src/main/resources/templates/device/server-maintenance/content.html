运维脚本规范建议

推荐把关键过程输出到标准输出，并在失败时返回非 0 退出码，这样页面才能准确显示每一步结果。
  • 文件名使用 `01-xxx.sh`、`02-xxx.sh` 这种有序格式。
  • 脚本开头建议加 `set -euo pipefail`，避免错误被吞掉。
  • 关键节点用 `echo` 打印，例如"开始安装 Docker""完成写入配置"。
  • 执行时会自动注入变量：`$server_ip` 为服务器 IP，`$server_host` 为服务器主域名或主机名，`$server_hosts` 为服务器可用 host 列表（bash array）。
  • 系统配置也会注入：`$airopscat_domain` 对应 `airopscat.domain`，`$airopscat_api_token` 对应 `airopscat.api.token`。
  • 可选元信息：前几行支持 `# @title: 安装 Docker`、`# @description: 安装容器运行时`。
  • 脚本尽量设计成幂等，失败后修复环境即可重试。
