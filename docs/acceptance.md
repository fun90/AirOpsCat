日期：2026-10-20。正式分支：`release/go`，历史重写分支：`rewrite/go`。本记录只把实际执行的检查标记为通过。

- 账户、用户、节点、服务器、标签、路由、订阅定制、收支和系统配置管理。
- 真实概览：账户状态、节点及待部署位、服务器与到期摘要、告警及最近事件。
- sing-box 配置生成、SSH 部署与 reload、成功部署快照、订阅与 docs-info、跨节点 guard 和配额差分统计。

## 运行边界

- 自动 DNS 当前按 vnstat 自然月统计，不支持供应商非自然月计费。未知远端操作保留待核查，不盲目重发。
- Guard 为单实例内存聚合；进程重启会重新累计。超限只拒绝新连接，不踢存量连接。
- 维护批次需要保持页面打开，各步骤独立服务器锁；断连时需核查实际服务器状态。
- 维护页面曾误发一次 `02-swap.sh` 测试请求后中断；已核查原 swap 文件未改写、无临时目录、sing-box active；该过程不视为批量初始化验收。
